# MeiliCarSDK

Spec repo for the Meili iOS SDK.

New versions publish as `MeiliCarSDK/<version>/MeiliCarSDK.podspec` (pod `MeiliCarSDK`). The
existing `MeiliSDK/<version>/` folders stay resolvable and are frozen at `1.11.1` — that pod name
is no longer published to, but old pins keep resolving. The spec source URL for consumers
(`https://github.com/meili-travel-tech/meili-ios-pods`) is unchanged either way.
